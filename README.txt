Дипломный проект. Задание 3: UI-тесты
Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers
Реализованные сценарии:
Восстановление пароля,
Тестирование Личного кабинета,
Тестирование страницы "Лента заказов",
Проверка основного функционала, в том числе: 
- редиректы по кнопкам «Конструктор» и «Лента заказов», 
- всплывающее окно с деталями ингредиента, 
- сценарий успешного оформления заказа.

Структура проекта
Все page_object -> в пакете page_objects

Фикстуры -> в файле conftest.py

Все тесты -> в пакете tests

Все локаторы -> в пакете locators

Запуск автотестов
Установка зависимостей

$ pip install -r requirements.txt

**Запуск автотестов **

$ pytest -v

**Формирование alure-отчётa в формате html **

$ allure serve allure_results
